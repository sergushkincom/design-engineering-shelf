# design-engineering-shelf

A short, opinionated shelf for designers who build: the books, courses, certifications, AI skills, talks and people that actually changed how I work — each with a price, a time cost, a level and a verdict.

Not an awesome-list. Deliberately small. If something is here, I've used it and I'd recommend it to a specific kind of person for a specific reason.

Maintained by [Denys Sergushkin](https://sergushkin.com) · Principal Product Designer · Agentic UX for B2B and ERP · I prototype in code.
Last updated: 2026-10-31

## How I pick

- I only list things I've actually read, taken, passed or used in real work. Backlog is separate.
- Every entry says who it's for and what it costs in money and hours. Prices are rough, USD, and change.
- When something is dated, overrated or only worth it for a narrow case, the entry says so. Entries get removed when I stop recommending them.

## Certifications

Triage for a designer moving into design engineering / agentic UX, as of Oct 2026.

- **[Claude Certified Architect – Foundations (CCA-F)](https://anthropic-partners.skilljar.com/claude-certified-architect-foundations-certification)** — Anthropic · Cert · $$ (~$125) · 3–5 weeks at ~1 h/day · Deep · **Worth it** — The only certification here that signals "designer who understands how agentic systems are actually built". 60 scenario questions, 120 min, pass 720/1000, online proctored; covers Claude Code, Agent SDK, Claude API and MCP, with Agentic Architecture (27%) and Context Management (15%) as the domains people underestimate. Questions test trade-off judgment, not definitions. Prep path: the official Exam Guide PDF as the syllabus, then the free Anthropic Academy courses (Claude 101, Building with the Claude API, Intro to MCP, Claude Code in Action), then one timed 60-question mock. Caveat: it's new, so treat it as an interview conversation-starter, not a CV filter.
- **[GitHub Foundations (GH-900)](https://education.github.com/experiences/foundations_certificate)** — GitHub · Cert · $ ($49; free voucher for verified students via GitHub Education) · 6–10 h · Starter · **Skim** — 60 questions, 100 min, pass 700/1000, valid 2 years. Repos, branches, PRs, Markdown, Projects, basic security and admin, Actions and Copilot at a "what is it" level; the Microsoft Learn "GitHub Foundations" path covers all of it. Near-zero weight on a senior designer's CV. Only worth a weekend if it's free or you want to close gaps in GitHub Projects, branch protection, CODEOWNERS and Dependabot.
- **[AWS Certified AI Practitioner](https://aws.amazon.com/certification/certified-ai-practitioner/)** — AWS · Cert · $ · 2–4 weeks · Working · **Skim** — A real, recognised foundational exam, but it's about the AWS ecosystem (Bedrock, SageMaker, governance). Becomes relevant only if you target AWS-heavy companies; parked until one shows up.
- **[Google AI Essentials](https://www.coursera.org/specializations/ai-essentials-google)** — Google / Coursera · Course · $ (subscription) · ~10 h · Starter · **Skip** — An introduction for people opening an AI assistant for the first time. If you already ship AI features, having it on your profile subtracts rather than adds.
- **[IBM Generative AI Engineering](https://www.coursera.org/professional-certificates/ibm-generative-ai-engineering)** — IBM / Coursera · Course · $ (subscription) · several months · Deep · **Skip** for designers — A path to becoming a GenAI/ML engineer: RAG, fine-tuning, LangChain, PyTorch, Python throughout. Not a design-engineering target. If you want engineering depth, cherry-pick one or two modules instead of the whole programme.
